1. THE BUG: Error Message Extraction Mismatch
================================================================================

BACKEND API RESPONSE STRUCTURE
--------------------------------------------------------------------------------
The backend uses ResponseBuilder (defined in src/core/utils/api/ApiResponse.ts)
which returns standardized error responses:

// Error response structure
{
  success: false,
  error: {
    message: string,    // ← Actual error message
    code: string,       // ← Error code (e.g., 'VALIDATION_ERROR')
    details?: object    // ← Additional error details
  }
}

FRONTEND ERROR PARSING (INCORRECT)
--------------------------------------------------------------------------------
All affected components parse errors like this:

// RegularPaymentTable.tsx:82-85
if (!res.ok) {
  const err = await res.json();
  throw new Error(err.error || 'Failed to collect payment');
  //              ^^^^^^^^^ ❌ WRONG - This is an OBJECT, not a string!
}

WHAT HAPPENS:
1. Backend returns:
   { success: false, error: { message: "Member not found", code: "NOT_FOUND" } }
2. Frontend does:
   new Error(err.error) → new Error({ message: "Member not found", code: "NOT_FOUND" })
3. JavaScript converts object to string: "[object Object]"
4. Toast displays: "[object Object]" ❌

LAYER 2: CREATE CENTRALIZED ERROR PARSER
--------------------------------------------------------------------------------
New File: src/lib/utils/api-error.ts

import { ApiErrorResponse } from '@/core/utils/api/ApiResponse';

/**
 * Parse API error response and extract human-readable message
 *
 * @param response - Fetch Response object
 * @returns Error message string
 */
export async function parseApiError(response: Response): Promise<string> {
  try {
    const data: ApiErrorResponse = await response.json();

    // Extract message from standardized error response
    if (data.error?.message) {
      return data.error.message;
    }

    // Fallback to top-level message (legacy)
    if ('message' in data) {
      return (data as any).message;
    }

    // Last resort
    return `Request failed with status ${response.status}`;
  } catch (parseError) {
    // JSON parsing failed
    return `Request failed with status ${response.status}`;
  }
}

Usage:
const res = await fetch('/api/members/${id}/payment', {...});
if (!res.ok) {
  const errorMessage = await parseApiError(res);
  throw new Error(errorMessage);
}
