## 1. Diagnosis

Before this work (`75eff38`), search engines had almost nothing to work with:

- **One page.** `/` carried all commercial intent. Navigation used `#` links within the page, the footer's About and Contact were `mailto:` links, and `/contact` had no links pointing to it.
- **No indexing basics.** No robots.txt, no sitemap, no canonical tags. Every public page inherited the homepage's title and `og:url`; `metadataBase` pointed at the apex host, which redirects to www; the `*.vercel.app` copy of the site was indexable.
- **Title and H1 said nothing useful.** `<title>Metric Gym OS</title>` and "The operating system for serious gyms." — neither mentioned gym management software or Sri Lanka.
- **Claims the code does not support.** Hikvision, RFID and face entry, WhatsApp messages, QR check-in, a trial on every tier, tier names (Starter/Growth) that do not exist in the product, and "automated fee collection" (members pay at the desk).
- **Not indexed under the current name.** `site:metricgymos.com` returned nothing. The retired metricgymmanager.com is still indexed with old claims: 25+ gyms, 7.9K members, 99.99% uptime, a 6,500 LKR Starter plan, a 14-day trial, WhatsApp reminders and trilingual support.

The Sri Lankan results for "gym management software/system Sri Lanka" are held by small local vendors (FitnessX, Fitrobit, Fitconnect, SyntaxGym, GymNow, Smart IT Solutions) whose pages state the category, the country, rupee prices and some proof. None of their sites is deep. Metric can compete on depth and accuracy; proof and links cannot be written in code.

If GA4 counts in-app page changes as page views and email redaction is off, that address reaches Google Analytics (SEO-056).

Rules that protect this work (rule 2.23 in `.claude/rules/architecture.md`):

- A new public page goes in the registry (`features/marketing/config/pages.ts`) **and** in `PUBLIC_ROUTES`; otherwise anonymous visitors and Googlebot get 307 → `/login` while every render test stays green.
- Never set `alternates.canonical` or `openGraph.url` in the root layout — every route inherits them.
- Public prices, tier names and trial terms come only from `features/marketing/config/pricing.ts`.
- Public copy states only what the code does; `HomePage.test.tsx` pins the claims that were removed.
- Structured data never carries ratings, reviews or `sameAs` without evidence, and every `@id` must resolve on its own page.
- Design-system primitives are imported from the barrel (`@/components/ui`), never a deep path — which is why SEO-055 is a design-system change, not a one-line import fix.
